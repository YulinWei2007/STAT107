# STAT 107 – Data Science Discovery

Lab exercises and coursework from STAT 107 (Data Science Discovery) at UIUC, 
covering foundational data science skills in Python.

## Labs

- **lab_intro** — introduction to Python and Jupyter Notebook
- **lab_pandas** — data manipulation with pandas
- **lab_plots** — data visualization
- **lab_probability** — probability fundamentals
- **lab_similarity** — similarity and distance metrics
- **lab_kmeans** — K-Means clustering
- **lab_regression** — linear regression
- **lab_gpa** — GPA data analysis
- **lab_illini** — analysis of a UIUC-related dataset
- **lab_justice** — analysis of a criminal/social justice dataset
- **lab_favorites** — exploratory data analysis project
- **lab_exp-design** — fundamentals of experimental design

## Tools
Python, pandas, matplotlib, Jupyter Notebook

## Notes
Each lab is a self-contained Jupyter notebook (.ipynb) completed as part of 
STAT 107 coursework.
